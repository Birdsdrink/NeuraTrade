Design System — AI Market Analysis Assistant

This folder contains the design system and per-screen UI/UX specifications for the AI Market Analysis Assistant mobile app. Use these docs to implement the visual language, components, and screens in the app.

Files:
- colors.md — color tokens and usage guidance
- typography.md — font choices and hierarchy
- components.md — reusable components, spacing, radii, shadows
- screens.md — per-screen specs for all requested screens
- animations.md — animation principles and micro-interactions

Principles: premium dark theme, generous spacing, minimal borders, strong typographic hierarchy, subtle accents and restrained color usage.
